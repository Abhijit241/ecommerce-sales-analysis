# Ecommerce Sales Analysis

## 📌 Project Overview
This project analyzes ecommerce sales data to identify sales trends, Mostly sales products, customer behavior, and regional performance.

---

## 🛠 Tools Used
- Excel
- PostgreSQL
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Power BI

---

## 📊 Key Analysis
- Monthly Sales Trend
- Region-wise Sales
- Top Products
- Customer Insights

---

## 📈 Dashboard Features
- Interactive Power BI Dashboard
- KPI Cards
- Sales Trend Analysis
- Regional Filtering
- Product Performance

---

## 🔍 Key Insights
- West region generated highest sales
- Furniture category had lower profit margins
- Seasonal sales peaks observed in Q4
- Top customers contributed significant revenue

## 📂 Project Files
- SQL Queries
- Python Analysis Notebook
- Power BI Dashboard
- Cleaned Dataset
